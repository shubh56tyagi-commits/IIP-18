
# 🌿 WildGuard - Wildlife and Nature Conservation Website

## 📌 About the Project

WildGuard is a website developed to spread awareness about
wildlife protection, endangered species, and nature conservation.

The main goal of this project is to encourage people to protect
animals, preserve forests, reduce pollution, and keep our planet green.

## 🎯 Objectives

- Spread awareness about wildlife protection.
- Provide information about endangered animals.
- Promote nature and environmental conservation.
- Encourage tree plantation and water conservation.
- Educate people about reducing pollution.
- Allow visitors to register using a simple registration form.

## 🛠️ Technologies Used

- HTML5 - To create the structure of the website.
- CSS3 - To design and style the website.
- JavaScript - To handle the registration form.

## ✨ Features

- Attractive homepage with a nature background.
- Navigation bar with section links.
- About section describing the conservation mission.
- Wildlife cards featuring animals.
- Nature conservation tips.
- Registration form for visitors.
- Registration success message displaying name and age.
- Hover effects and responsive design.
- Simple and user-friendly interface.

## ▶️ How to Run the Project

1. Download or copy the project files.
2. Open the project folder in Visual Studio Code.
3. Make sure index.html, style.css, and script.js
   are saved in the same folder.
4. Open index.html in your web browser.
5. You can also use the Live Server extension in VS Code.
6. Ensure you have an internet connection to load online images.

## 📝 Registration Form

The registration form asks visitors to enter their name and age.

JavaScript handles the form submission and displays a
"Registration Successful" message with the submitted details.

Note: This is a frontend demonstration. Registration data
is not stored in a database.
